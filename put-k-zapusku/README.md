# Путь к запуску

Мод для Claude Code: панель сбоку от чата. Показывает, где проект сейчас, и помогает не отвлекаться.

Что умеет: два процента наверху (весь продукт и текущий запуск) со стрелкой на большой роадмап, блок «Сегодня» для плана дня, этап «Сейчас» с тремя горящими пунктами (горит, ждёт тебя, решение), кнопки «Делаем» и «Потом», «+ Сегодня» и «В сеанс» у каждого шага, замок по зоне n8n и сервер для параллельных сеансов, свёрнутая карточка.

Данные берёт из файла `ЭТАПЫ.md` в папке проекта (или в `01_Память-Клода/`). Пример и описание меток — в `examples/ЭТАПЫ.md` и в README репозитория. Ключей и паролей мод не читает и не пишет.

Открыть панель: сама открывается в начале сеанса, вручную командой `/zapusk`. Править: менять файлы в этой папке и выполнить `/reload-plugins`. Проверка: `claude plugin test <папка>`.
